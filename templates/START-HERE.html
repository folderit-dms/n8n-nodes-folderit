Start on your own computer

  1. Open your n8n instance. An owner/admin installs Folderit from the workflow's + → search Folderit panel. Installation and connection guide.
  2. Download one workflow JSON above. In a blank n8n workflow, use the top ⋯ → Import from File. Keep the workflow inactive.
  3. Find the lower branch 1. Set up receipt table. Choose a stable table name in Ledger setup settings, then run only that manual branch. Run setup once at a time in the same n8n project.
  4. Open Copy ledgerTableId into Settings. Copy the table ID into the main Settings node. Replace every remaining YOUR_… placeholder.
  5. Select your saved Folderit OAuth2 API credential in every Folderit node. Connect your dedicated IMAP mailbox or delegated Microsoft Teams account in the provider node. Passwords and secrets belong only in n8n's credential dialog.
  6. Read the coloured setup, behavior and recovery notes. Test synthetic input and inspect the actual Folderit files or Teams channel. Repeat the same input, then test a controlled failure. Activate only after these checks pass.

The receipt table belongs inside your n8n project. Uploaded files belong in your chosen Folderit folder. No local Windows/macOS folder is created automatically.

When a run fails

Open n8n's saved execution, inspect its pending receipt and check the actual destination. An uncertain result keeps processing blocked for inspection. Never clear a lock while its owner may still be running. Preserve completed receipts.

Optional email alerts: import the shared SMTP error workflow, configure its sender/recipient and SMTP credential, then select it under the main workflow's ⋯ → Settings → Error workflow. Verify actual delivery with a controlled error in an activated test workflow.
